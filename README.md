# BossPilot

基于 Python、PySide6、uv 和 DrissionPage 的 BOSS 岗位筛选工具。

## 开始使用

```bash
uv sync
uv run python main.py
```

在界面中设置地区、搜索词、岗位名称关键词、薪资、工作经验和学历后，点击“开始采集”。程序会打开 Chromium 并逐步滚动岗位列表；启用“匹配后立即沟通”时，会对符合条件且尚未沟通的岗位发起沟通，然后继续处理下一条。匹配结果可以导出为 CSV，双击岗位可以打开详情页。

浏览器固定使用项目的 `user_data/` 目录保存登录状态。如遇登录或安全验证，请在程序打开的浏览器中完成。请遵守目标平台的服务条款、频率限制和隐私要求。

沟通历史按 JSON Lines 格式追加保存在 `data/contact_history.jsonl`，每行包含岗位字段、沟通状态、搜索条件和时间。新发起的沟通记录准确的 `contacted_at`；网页仅显示“此前已沟通”时无法取得原始时间，因此只记录本次发现时间 `recorded_at`。界面中的“沟通记录”按钮可以直接打开该文件。
