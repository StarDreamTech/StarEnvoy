基于 Python、PySide6、uv 和 DrissionPage 的 BOSS 岗位筛选工具。

## 开始使用

```bash
uv sync
uv run python main.py
```

界面分为四个标签页：

- **采集设置**：地区、搜索词、岗位名称关键词、薪资、工作经验、学历，以及采集轮数、沟通间隔等行为开关。设置会自动保存，下次启动沿用。
- **岗位结果**：本次采集匹配到的岗位。次要列默认隐藏，勾选“显示全部列”可展开，隐藏的列同样会采集并写入导出的 CSV。双击一行打开岗位页，双击“职位描述”查看完整招聘要求。
- **沟通记录**：读取 `data/contact_history.jsonl` 并按时间倒序展示全部历史沟通。
- **采集日志**：每个岗位读到的字段与被筛掉的原因。

设置好条件后点击顶部的“开始采集”。程序会打开 Chromium 并逐步滚动岗位列表；启用“匹配后立即沟通”时，会对符合条件且尚未沟通的岗位发起沟通，然后继续处理下一条。开启“岗位详情”时，还会点开匹配到的岗位卡片，读取列表页右侧的职位描述、技能标签、福利、工作地址与 HR 信息。

浏览器固定使用项目的 `user_data/` 目录保存登录状态。如遇登录或安全验证，请在程序打开的浏览器中完成。请遵守目标平台的服务条款、频率限制和隐私要求。

沟通历史按 JSON Lines 格式追加保存在 `data/contact_history.jsonl`，每行包含岗位字段、沟通状态、搜索条件和时间。新发起的沟通记录准确的 `contacted_at`；网页仅显示“此前已沟通”时无法取得原始时间，因此只记录本次发现时间 `recorded_at`。“沟通记录”标签页会直接展示这些记录，点“打开文件”可以查看原始 JSONL。
